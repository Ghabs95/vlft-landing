# VELOFIT STUDIO — Marketing & SEO Landing Page 🌐

> The official landing and documentation website for **Velofit Studio** (`https://velofit.studio`), deployed on Cloudflare Pages.

---

## 🚴 Overview

This repository hosts the marketing, features showcase, scientific literature background, and FAQ for **Velofit Studio** — the AI-powered biomechanical bike fitting web suite.

- **Production URL**: `https://velofit.studio` & `https://www.velofit.studio`
- **Application URL**: `https://app.velofit.studio` (repo: `vlft-app`)

---

## 🛠️ Tech Stack

- **HTML5 & CSS3**: Modern dark-mode cycling aesthetic with CSS variables and responsive glassmorphism.
- **Vanilla JavaScript**: Lightweight, zero-dependency i18n controller with persistent language state.
- **Dual Localization**: Complete Italian 🇮🇹 and English 🇬🇧 language support.

---

## 🚀 Local Development

Open `index.html` directly in any browser:
```bash
open index.html
```

Or run a local server:
```bash
npx serve .
```
